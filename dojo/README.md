# Badge Dojo formations

Lineups for the five element dojos (Water, Fire, Grass, Rock, Lightning), Dojo 1–7, stages 1–10 each:
**350 stages** from **118 reviewed records**, published as 109 cards at `/dojo/<element>/`.

- `reviewed-dojo-formations.json` is the reviewed source data. Each record has the element, Dojo number,
  `website_stage_numbers`, the original Discord message (ID, URL, thread, poster, `posted_at` from the
  message snowflake), the attachment index used, the capture type, the stage shown in the screenshot,
  and a `board` of 4 rows × 3 columns. Row 1 is the front (nearest the enemy); columns run left to right.
- `dojo-lineups.json` is generated by `stage-47/build_site.py` with normalized lineups and stage coverage.

Sources were found by searching the Clash of Critters Discord for `<element> dojo has:image` and reading
complete floor guides first. Stage assignment follows each author's caption. A `post_clear` screenshot
shows the next stage after the clear; `setup_screen` shows the stage being set up; `crop` images were
placed on the grid from tile spacing.

Every selected board has five units of the dojo's element with unique families, and each stage has exactly
one selected formation. Lightning Dojo 2 uses ~Nic's July 19, 2026 post because no newer complete reference
was found; all other sources were posted after August 27, 2026. Outcomes are author-reported, not tested in game.
