Privacy Policy

Overview

Critter Formations is a static website with no accounts and no server-side code of its own. This page explains what limited data is collected when you visit or send feedback.

Hosting (GitHub Pages)

This site is hosted on GitHub Pages. GitHub may log visitor IP addresses and request data for security purposes. See GitHub’s General Privacy Statement.

Analytics (Google Analytics 4)

This site uses Google Analytics 4 to understand traffic and improve the content. GA4 sets cookies such as _ga and collects usage data including pages viewed, approximate location, and device/browser information. See Google’s policy on partner sites. You can opt out using the Google Analytics Opt-out Browser Add-on.

Donations (PayPal)

The donate button links to PayPal, which processes payments under its own privacy policy. This site never sees your card or payment details.

Discord links

Card titles and poster names link to the original Discord posts used as sources. Visiting those links is subject to Discord’s own privacy practices.

Feedback (Supabase)

The feedback form sends your star rating, message, optional email address, the page you were on and the site language to a database hosted by Supabase. Feedback is only used to improve this site; it is never published or sold. Leave the email field empty if you don’t need a reply.

No accounts, no data sold

This site does not require an account and does not sell data. Apart from feedback you choose to send, it does not store any personal data.

Contact

Questions about this policy can be filed as a GitHub issue.
