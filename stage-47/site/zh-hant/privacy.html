隱私權政策

概述

Critter Formations 是一個靜態網站，沒有帳號，也沒有自己的伺服器端程式。本頁說明您造訪網站或送出意見回饋時，會收集哪些有限的資料。

託管（GitHub Pages）

本網站託管於 GitHub Pages。GitHub 可能基於安全目的記錄訪客的 IP 位址與請求資料。請參閱 GitHub 的一般隱私權聲明。

分析（Google Analytics 4）

本網站使用 Google Analytics 4 了解流量並改善內容。GA4 會設定 _ga 等 Cookie，並收集使用資料，包括瀏覽的頁面、大致位置及裝置／瀏覽器資訊。請參閱 Google 的合作夥伴網站政策。您可以使用 Google Analytics 停用瀏覽器外掛程式選擇退出。

贊助（PayPal）

贊助按鈕會連到 PayPal，由 PayPal 依其隱私權政策處理付款。本網站不會看到您的信用卡或付款資訊。

Discord 連結

卡片標題與發布者名稱會連到作為資料來源的 Discord 原始貼文。造訪這些連結時，適用 Discord 自己的隱私權規範。

意見回饋（Supabase）

意見回饋表單會將您的星等評分、留言、選填的電子郵件、您所在的頁面與網站語言，傳送到由 Supabase 託管的資料庫。這些回饋只用於改善本網站，絕不會公開或販售。如果不需要回覆，請將電子郵件欄位留空。

無帳號、不販售資料

本網站不需要帳號，也不販售資料。除了您主動送出的意見回饋之外，本網站不儲存任何個人資料。

聯絡方式

對本政策有任何疑問，歡迎提交 GitHub issue。
